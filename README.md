# THE GEOPOLITICAL LENS — FINAL STARTER

This is your complete static website package.

## Pages
- `index.html` — homepage
- `articles.html` — article archive with category filters
- `articles/what-is-geopolitics.html` — first article
- `styles.css` — design
- `script.js` — menu and article filtering
- `assets/` — place for your future images

## Before publishing
Replace:
- `YOUR_EMAIL@example.com`
- LinkedIn link
- YouTube link
- CV link
- placeholder profile text
- sample article text/references
- add your photograph to `assets/`

## Adding a future article
1. Create a new HTML file inside `articles/`.
2. Copy the structure of `what-is-geopolitics.html`.
3. Change the title, date, category and article text.
4. Add a new card to `articles.html`.

## Important
This is a static website. Your computer does not need to remain on after the site is hosted.
